# Updating the resume
Resume content lives in `src/data/resume.js` and feeds both the site and the PDF.
After editing it, run `npm run resume` to regenerate `src/Assets/Snehresume.pdf`
(needs Chrome, Brave, Chromium or Edge installed; set `CHROME_PATH` to override).
